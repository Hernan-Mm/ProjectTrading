# Project Trading

## Descripción

Project Trading es un proyecto experimental de ingeniería de software e ingeniería de IA orientado al estudio y desarrollo progresivo de un sistema de trading comprensible, reproducible y documentado.

## Objetivos

- Desarrollar habilidades de ingeniería de IA, agentes y orquestación.
- Aplicar desarrollo guiado por especificaciones.
- Diseñar una arquitectura modular y reemplazable.
- Investigar datos de mercado, estrategias, backtesting, riesgo y ejecución.
- Mantener testing, documentación y revisión humana como partes del proceso.
